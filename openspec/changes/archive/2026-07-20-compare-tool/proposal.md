## Why

我需要一个自己常用的在线工具集合系统，把日常高频的小工具集中在一个统一入口里。第一个要做的工具是"数据比对工具"：把两个接口返回的 JSON（或两段字符串）粘进来，快速判断它们是否一致，并在不一致时把具体差异清楚地列出来。当前没有任何代码，本次变更负责搭起系统骨架并交付第一个工具。

## What Changes

- 新建工具集合系统外壳：统一的页面布局、工具导航入口，能够低成本地不断挂载新工具（比对工具是首个）。
- 新建"数据比对工具"，包含：
  - 顶部 **字符串 / JSON** 两种比对模式切换。
  - 左右两个输入区，JSON 模式下自动**格式化展示**（缩进、语法高亮、错误标注），基于 CodeMirror 编辑器。
  - 各自计算并展示 **hash**：JSON 模式按**规范化后**内容算（key 排序、压缩空白），字符串模式按原始文本算。
  - hash 一致性判定；不一致时在下方结果区列出差异。
  - JSON 差异按 **JSON Path 定位**，分三类展示：值不同 / 右侧多出 / 右侧缺失；提供**扁平路径**与**树形高亮**两种视图可切换。
  - 字符串差异为逐行 diff，视图切换按钮在该模式下禁用。
- 技术选型定为 **Next.js（React）**，为后期"直接填接口 URL、由后端代理拉取再比对"预留架构位置（本次**不实现**代理功能，仅留位）。

## Capabilities

### New Capabilities
- `tool-shell`: 工具集合系统的外壳——统一布局、工具导航、承载并扩展多个独立工具的框架。
- `data-compare`: 数据比对工具——字符串/JSON 两种模式的内容比对、hash 计算与差异展示。

## Impact

- 全新项目，从零初始化 **Next.js + React + TypeScript** 工程。
- 引入依赖：CodeMirror 6（编辑器/高亮/格式化）、JSON 规范化与 diff 相关工具库、hash 算法（如 SHA-256，Web Crypto 或轻量库）。
- 架构预留后端 API route（代理外部接口），本次不落地具体实现。
