## Context

### 现状
①提供请求组装管线（Auth 注入 → Query 合并 → Body 序列化 → 信封 → `POST /api/request`）；②补齐集合 / 历史 / 会话持久化与 `lib/db`。当前请求中的 host / token / 密钥写死，多环境需逐个手改。

### 纲领与本层定位
本 change 为四层路线图第 ③ 层（environments），依赖 ②。纲领推论：**③ 只需在组装管线最前插入「变量替换」段，对已有逻辑零改动**。数据模型 `api_environments` / `api_variables`（② 已起 DB，③ 加两表）；变量作用域仅**环境级 + 全局级**（集合级后置），优先级 **环境 > 全局**。见已归档的 `add-api-client-core/design.md`。

### 约束
Next.js App Router；沿用 better-sqlite3（`lib/db`）、CodeMirror、暗色设计系统、`useReducer`；能不加依赖就不加。① 的组装子逻辑与 ② 的持久化能力不改，替换段纯叠加。

## Goals / Non-Goals

**Goals（本 change ③）:**
- 环境 CRUD + 单激活切换（`api_environments`，含「无环境」）。
- 变量 CRUD：环境级 / 全局级、启用 / 禁用（`api_variables`）。
- `{{变量}}` 替换引擎：管线最前段、「环境 > 全局」优先级、仅 enabled 生效、未定义原样 + 提示。
- 替换后预览（发送前查看实际请求）。
- 环境切换器 + 变量编辑面板 UI。

**Non-Goals:**
- 集合级 / 请求级变量作用域（后置）。
- 动态 / 脚本变量（`{{$timestamp}}`、faker 等）→ ⑤脚本域，不做。
- 变量值内递归引用其他变量（第一版单趟替换，不递归展开）。
- 密钥加密存储（第一版明文，本地自用）。
- 导入 / 代码生成（④）。

## Decisions

### 替换段插入组装管线「最前」
```
RequestDraft
  → 0. 变量替换 {{key}}→值   ← ③ 新增（本层）
  → 1. Auth 注入 → header/query   （①，不改）
  → 2. Query 合并 params[] → URL  （①，不改）
  → 3. Body 序列化 → wire body    （①，不改）
  → 信封 → POST /api/request
```
对 ① 逻辑零改动（纲领推论）。*备选*：各字段用到时各自替换——分散、易漏，集中在管线最前一次性替换更内聚。

### 作用域两层，优先级「环境 > 全局」
`api_variables.env_id=null` 表全局，非空表某环境。解析时合并「激活环境变量 + 全局变量」，同名以环境覆盖全局，仅 `enabled` 参与。*备选*：加集合级作用域——design.md 已后置，YAGNI。

### 未定义变量：保留原样 + 提示，不阻断
调试期常有临时缺值，阻断发送太重。未匹配的 `{{key}}` 原样保留并给出可见提示（高亮 / 发送前预览），不报错。*备选*：发送即报错——太严，否决。

### 替换实现：纯字符串 `{{key}}` 扫描，不引模板引擎
对 url / params / headers / body(raw、urlencoded、form-data 文本字段) / auth 的字符串值做 `{{key}}`→value 扫描替换。*备选*：handlebars 等模板引擎——引依赖且过强（不需要逻辑 / 循环 / 过滤器），KISS 用正则扫描。

### 单激活环境（`is_active`）
同一时刻至多一个环境激活，可切到「无环境」（仅全局生效）。激活态存 DB（跨会话一致）。*备选*：多环境叠加生效——语义复杂、优先级难定，否决。

### 替换发生在前端组装管线内
前端替换后再把信封发给 `/api/request`，代理**不感知变量**。*备选*：代理端替换——代理需读变量表，产生耦合；变量是前端概念，前端替换更内聚。

### 单趟替换，值内 `{{}}` 不二次解析
一次扫描完成替换；变量值里若再含 `{{}}` 不再递归展开，避免自引用成环。*备选*：递归展开——需环检测，复杂度高，第一版否决。

## Risks / Trade-offs

- **变量明文存储** → 本地自用可接受；对敏感值提供掩码显示并提示勿公网部署 / 勿提交。
- **`{{` 与目标内容里的字面 `{{` 冲突**（罕见）→ 第一版不支持转义，文档说明；后续可加 `\{{` 转义。
- **未定义变量静默原样易误发** → 以可见提示（高亮 + 发送前预览）缓解。
- **form-data 文件字段不参与替换**（文件不持久）→ 仅文本字段替换，符合预期。
- **递归 / 自引用变量** → 第一版单趟不递归，规避环；文档说明。

## Migration Plan

- **建表** `api_environments` / `api_variables`（`IF NOT EXISTS`），幂等；②→③ 升级后空表即「无环境 + 无变量」，管线无变量时输出等同 ①/②。
- **回滚**：`DROP` 两表 + 移除管线最前的替换段（回到 ②），不影响 ②。

## Open Questions

- 敏感变量是否加 `secret` 标记并掩码显示？倾向加简单掩码，实现时定。
- 未定义变量提示形态：内联高亮 vs 发送前汇总，实现时定。
- 是否允许「无环境」时也能用全局变量？倾向允许（全局始终生效），实现时确认。
