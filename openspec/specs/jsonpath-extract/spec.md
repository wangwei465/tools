# jsonpath-extract Specification

## Purpose

JSONPath 求值能力——对任意 JSON 文档以 JSONPath 表达式提取命中节点，支持根/子节点、递归下降、数组索引与切片、通配符与过滤表达式，并对每个命中同时给出值与源文档中的完整路径；求值全程在浏览器端完成，不出网、不落库、不借助宿主环境的原生 JavaScript 执行能力；对 JSON 非法 / 表达式非法 / 零命中三类反馈明确区分，并对文档大小与命中条数设定可提示的上限。该能力被「编码转换」的 JSONPath 提取器与接口调试响应区的 JSONPath 视图共同复用。

## Requirements

### Requirement: JSONPath 表达式求值
系统 SHALL 接受一个 JSONPath 表达式与一个 JSON 文档，返回文档中全部命中节点的值，并覆盖根节点、子节点、递归下降、数组索引、数组切片、通配符与过滤表达式等常用语法。

#### Scenario: 点路径取值
- **WHEN** 用户对 `{"a":{"b":{"c":1}}}` 求值表达式 `$.a.b.c`
- **THEN** 系统返回单个命中，值为 `1`

#### Scenario: 递归下降
- **WHEN** 用户对含多层嵌套的文档求值表达式 `$..id`
- **THEN** 系统返回文档中所有层级下名为 `id` 的字段值，不限深度

#### Scenario: 数组索引取值
- **WHEN** 用户对 `{"hits":[{"x":1},{"x":2}]}` 求值表达式 `$.hits[1].x`
- **THEN** 系统返回单个命中，值为 `2`

#### Scenario: 数组切片
- **WHEN** 用户对含 5 个元素的数组求值表达式 `$.list[0:2]`
- **THEN** 系统返回前两个元素，不包含下标为 2 的元素

#### Scenario: 通配符展开
- **WHEN** 用户对 `{"m":{"a":1,"b":2}}` 求值表达式 `$.m.*`
- **THEN** 系统返回该对象全部直接子节点的值

#### Scenario: 过滤表达式
- **WHEN** 用户对 `{"list":[{"p":5},{"p":20}]}` 求值表达式 `$.list[?(@.p>10)]`
- **THEN** 系统仅返回满足条件的元素

### Requirement: 命中路径输出
系统 SHALL 对每个命中结果同时给出该节点在源文档中的完整路径，使用户可定位来源，而不仅得到孤立的值。

#### Scenario: 结果附带路径
- **WHEN** 表达式 `$..id` 在文档中产生多个命中
- **THEN** 系统对每个命中分别展示其值与对应路径（如 `$.hits.hits[0]._source.id`）

#### Scenario: 路径可复制
- **WHEN** 用户需要复用某个命中的定位信息
- **THEN** 系统提供将该命中路径复制到剪贴板的方式

### Requirement: 求值结果的错误分类
系统 SHALL 将求值的失败与空结果区分为三类语义互不重叠的反馈：JSON 文档非法、表达式非法、表达式合法但零命中；其中零命中 SHALL 作为成功结果处理，MUST NOT 表述为错误。

#### Scenario: JSON 文档非法
- **WHEN** 用户提供无法解析的 JSON 文本
- **THEN** 系统提示 JSON 本身非法并附解析原因，不提示表达式有误

#### Scenario: 表达式非法
- **WHEN** 用户输入语法非法的 JSONPath 表达式
- **THEN** 系统提示表达式语法错误，且提示内容与 JSON 非法的提示明确区分

#### Scenario: 零命中为正常结果
- **WHEN** 表达式语法合法但在文档中无任何匹配
- **THEN** 系统以「无匹配」提示呈现，不使用错误样式，用户据此可确认该路径确实不存在

#### Scenario: 不抛出未捕获异常
- **WHEN** 求值过程遇到任何非法输入
- **THEN** 系统以结构化结果返回错误信息，不产生未捕获异常导致界面崩溃

### Requirement: 规模上限保护
系统 SHALL 对参与求值的 JSON 文档大小与返回的命中条数设定明确上限，超限时 SHALL 给出可读提示，MUST NOT 静默截断或使界面失去响应。

#### Scenario: 文档超出大小上限
- **WHEN** 待求值的 JSON 文本超过既定大小上限
- **THEN** 系统拒绝求值并提示当前大小与上限值，不进行部分解析

#### Scenario: 命中条数超出上限
- **WHEN** 表达式命中数量超过既定条数上限
- **THEN** 系统展示上限以内的结果，并明确告知总命中数与已截断的事实

### Requirement: 纯客户端求值与执行安全
求值 SHALL 全程在浏览器端完成，MUST NOT 发起网络请求，MUST NOT 将文档或表达式持久化到后端存储；过滤表达式的求值 MUST NOT 借助宿主环境的原生 JavaScript 执行能力（如 `eval` / `Function`）。

#### Scenario: 求值不出网
- **WHEN** 用户执行任意 JSONPath 求值
- **THEN** 结果由客户端计算得出，不产生对后端 API 或第三方服务的请求

#### Scenario: 无持久化
- **WHEN** 用户求值后刷新或离开页面
- **THEN** 文档内容与表达式不被写入后端库，仅存在于会话内存中

#### Scenario: 禁用原生执行
- **WHEN** 表达式包含过滤条件需要求值
- **THEN** 系统使用受限的表达式求值方式完成计算，不调用宿主环境的原生 JavaScript 执行能力
