# tool-shell Specification

## Purpose

工具集合系统外壳——提供统一的 Web 外壳作为多个独立工具的容器，包含全局布局与工具导航入口，并以每个工具独立页面/模块的方式组织，使新工具能够以最小成本挂载且互不影响。

## Requirements

### Requirement: 工具集合系统外壳
系统 SHALL 提供一个统一的 Web 外壳，作为多个独立工具的容器，包含全局布局与工具导航入口，使新工具能够以最小成本挂载。

#### Scenario: 访问系统首页
- **WHEN** 用户访问系统根路径
- **THEN** 系统展示统一的外壳布局，并列出可用工具的导航入口（至少包含"数据比对工具"）

#### Scenario: 进入具体工具
- **WHEN** 用户从导航点击"数据比对工具"
- **THEN** 系统在外壳内加载该工具页面，且全局导航保持可用

### Requirement: 工具可扩展性
系统 SHALL 以每个工具独立页面/模块的方式组织，新增工具时不需要改动其他工具。

#### Scenario: 新增一个工具
- **WHEN** 开发者新增一个工具模块并注册到导航
- **THEN** 该工具出现在导航入口中，且现有工具的行为不受影响
